## Object Oriented R6 API

- [`description`](https://desc.r-lib.org/dev/reference/description.md) :
  Read, write, update, validate DESCRIPTION files

## Utilities and Metadata

- [`check_field()`](https://desc.r-lib.org/dev/reference/check_field.md)
  : Syntactical check of a DESCRIPTION field
- [`cran_ascii_fields`](https://desc.r-lib.org/dev/reference/cran_ascii_fields.md)
  : The DESCRIPTION fields that are supposed to be in plain ASCII
  encoding
- [`cran_valid_fields`](https://desc.r-lib.org/dev/reference/cran_valid_fields.md)
  : A list of DESCRIPTION fields that are valid according to the CRAN
  checks
- [`dep_types`](https://desc.r-lib.org/dev/reference/dep_types.md) :
  DESCRIPTION fields that denote package dependencies
